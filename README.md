# Python E-Commerce Web Scraper

A lightweight, automated Python web scraper built with **BeautifulSoup**, **Requests**, and **Pandas**. It extracts structured product details (titles, prices, and descriptions) from an e-commerce catalog and exports the cleaned dataset directly into an Excel spreadsheet (`.xlsx`).

## Features
* **Automated Data Extraction:** Parses HTML product cards cleanly using BeautifulSoup.
* **Custom Request Headers:** Uses browser `User-Agent` headers for reliable page retrieval.
* **Structured Excel Export:** Formats extracted records into rows and columns via Pandas and saves them to `scraped_phones.xlsx`.

## Tech Stack
* **Python 3**
* `requests`
* `beautifulsoup4`
* `pandas`
* `openpyxl`
